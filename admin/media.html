Gérer les médias

Importe ici les photos du Portfolio, compose les séries (photos choisies librement parmi tous les univers) et dépose les vidéos des rubriques en pause (replié en bas de page).
Les autres photos du site (bannières, prestations, articles, portrait…) se changent dans l'éditeur visuel ci-dessous : clique la photo sur le vrai site et dépose ton fichier.
Gérés dans le code du site (pas via ce panel) : les vidéos de fond de l'accueil, le logo et le favicon. Dis-le-moi si tu veux les changer.
